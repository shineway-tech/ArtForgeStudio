# Elunvi Canvas 图生视频与内嵌播放器设计

## 目标

在图片查看器中把原“编辑”入口改为“生成视频”，并把现有局部图片编辑能力移动到右侧操作区，命名为“局部修改”。点击“生成视频”进入独立设置页：左侧持续展示源图片或生成结果，右侧编辑提示词并选择画面比例、清晰度与 4–15 秒时长；底部按钮展示服务端实时报价。任务成功后左侧原位切换为 Elunvi 自定义播放器。

首版仅使用服务端下发的默认视频模型，不向用户暴露模型选择器。

## 界面与交互

### 图片查看器入口

- 底部原“编辑”按钮变为“生成视频”，保留在相同位置。
- 右侧原“使用提示词”按钮变为“局部修改”，调用现有图片编辑回调。
- “再次生成”等既有操作保持不变。

### 视频设置页

- 顶部提供返回按钮、标题和当前源图片名称。
- 左侧为大尺寸预览区。任务提交前显示源图片；生成中显示进度遮罩；成功后原位显示播放器。
- 右侧上方为可编辑多行提示词，初始值取当前图片提示词。
- 参数区包含：
  - 比例：`21:9`、`16:9`、`4:3`、`1:1`、`3:4`、`9:16`。
  - 清晰度：`480P`、`720P`、`1080P`。
  - 时长：4–15 秒整数，支持滑杆、减号和加号，步长 1 秒。
- 底部主按钮同时显示“生成视频”和所需积分。报价加载、参数无效、余额不足或任务进行中时展示相应禁用状态。

### 自定义播放器

播放器控制层由 Elunvi 绘制，提供播放/暂停、进度拖动、当前时间/总时长、音量与静音、循环、全屏、下载/打开文件夹和再次生成。Windows/macOS 使用现有 Wry 依赖承载受控 HTML5 `<video>`，Wry 只负责视频解码与画面输出；导航、新窗口和任意网络地址均被禁止。播放器只加载应用已经校验并保存到本地的视频文件。

## 服务端权威数据与接口

模型能力、可选参数和积分价格由服务端权威下发，客户端内置的参数仅用于无数据时的界面约束，不作为计费依据。

### 报价

新增 `POST /v1/generation/video-quotes`：

- 请求：模型代码、源文件 ID、比例、清晰度、时长秒数。
- 响应：`quote_id`、十进制字符串 `credit_cost`、`expires_at`、规范化后的参数。
- 客户端参数变化后短暂防抖再报价；主按钮仅在最新报价有效时启用。
- 服务端提交时必须复核报价归属、有效期和参数，客户端显示值不参与最终扣费判断。

### 任务提交

沿用 `POST /v1/generation/tasks`，新增 `task_type = image_to_video` 所需字段：`source_file_id`、`resolution`、`duration_secs` 和 `quote_id`。继续使用稳定的 `client_request_id` 保证幂等。

服务端验证能力与报价后预留积分，调用默认视频供应商。客户端沿用现有任务详情轮询、取消和恢复协议。成功输出为带 MIME 类型、字节数和 SHA-256 的视频文件；客户端严格执行“下载并校验 → 原子写入 → 更新本地元数据 → 确认服务端交付”。失败或取消后的积分释放由服务端任务状态决定。

## 客户端状态

新增独立视频工作区状态，保存源资产 ID/路径、源文件 ID、提示词草稿、选择参数、报价、任务 ID、进度、错误和本地视频路径。关闭或重启后，未完成任务使用现有恢复记录继续查询；已下载的视频作为本地资产保存，不覆盖源图片。

状态机：

`Editing → Quoting → Ready → Submitting → Queued/Running → Downloading → ReadyToPlay`

任一步骤失败进入可重试的 `Failed`，参数变化会使旧报价立即失效。重复点击、超时重试和恢复均复用同一个请求 ID，避免重复任务与重复扣费。

## 错误处理与安全

- 未登录、无默认视频模型、服务端暂不支持、余额不足、报价过期、源图片上传失败、任务失败、下载校验失败分别显示可理解的中文提示。
- 不在日志中记录提示词、文件签名 URL、响应正文或认证信息。
- 本地视频 URL 由 Rust 生成，不接收页面脚本传入的任意路径。
- WebView IPC 只接受白名单播放器命令并验证数值范围。
- 关闭设置页不会取消服务端任务；用户显式取消时才调用取消接口。

## 测试与验收

- 协议单元测试：报价序列化、视频任务字段、十进制积分、过期报价和幂等 ID。
- UI 结构测试：查看器两个入口、设置页全部比例/清晰度/时长范围、积分按钮与状态文案。
- 状态测试：参数变化使报价失效；失败可重试；同一任务不重复提交；成功交付顺序正确。
- 播放器测试：只接受本地视频、播放状态同步、拖动/音量/循环/全屏 IPC 白名单。
- Windows 实机验收：从图片查看器进入、修改提示词与参数、看到报价、提交任务、进度更新、结果原位播放；退出重开后任务或已下载视频可恢复。

## 兼容与发布

当当前服务端尚未下发视频模型或报价接口不可用时，入口与完整设置页仍可展示，但生成按钮明确显示“视频服务暂未开放”，不得使用客户端假价格或伪造成功结果。图片生成、局部修改和现有作品数据不受影响。
